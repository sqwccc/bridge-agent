三、访问路径与转发规则
直接访问：http://3.141.179.12:18089/zntmh/ql/
大屏：http://3.141.179.12:18089/zntmh/ql/screen
门户访问：<门户协议及主机端口>/zntmh/ql/
不要把门户菜单配置成相对路径 zntmh/ql/，否则可能落到 /pc/zntmh/ql/。
菜单应使用 /zntmh/ql/ 或完整 URL；/pc/zntmh/ql/ 不在这次确认的配置范围。
根路径 / 不作为本版完整前端的标准入口。

门户 Nginx 配置（放在正确的 server 中）：
location = /zntmh/ql { return 301 /zntmh/ql/; }
location ^~ /zntmh/ql/ {
    proxy_pass http://3.141.179.12:18089/;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header Connection "";
    proxy_buffering off;
    proxy_cache off;
    proxy_connect_timeout 10s;
    proxy_read_timeout 300s;
    proxy_send_timeout 300s;
}
proxy_pass 尾部的 / 将门户 /zntmh/ql/ 前缀剥掉：
浏览器 /zntmh/ql/api/v1/auth/config -> 镜像 /api/v1/auth/config -> Java 同路径。
镜像 deploy/cce/nginx.portal.conf 同时接受保留前缀的直接访问：
location = /zntmh/ql { return 301 /zntmh/ql/; }
location ^~ /zntmh/ql/ { rewrite ^/zntmh/ql/(.*)$ /$1 last; }
absolute_redirect off 防止镜像端口/主机泄漏到重定向。
不要给镜像 / 添加无条件跳转到 /zntmh/ql/，门户剥掉前缀后可能造成重定向循环。
镜像 /api/ 转发 Java8088；/assets/ 文件缺失应返回404，避免 HTML 被当成 JS。
镜像 API proxy_read_timeout 为200s，门户为300s；并非整个链路都能空闲300s。
当前 SAMEORIGIN 限制意味着跨域 iframe 还需单独核对，同源门户转发与直接跨域 iframe 不等价。
