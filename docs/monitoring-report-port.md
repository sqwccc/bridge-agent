# 监测报告页面移植

入口：桥梁详情 → 桥梁检测报告 → 生成监测报告。原有来源附件列表、预览和下载保留。
参考桌面“桥梁智能体_平台接入版_v3.2”的 report.js 七章结构与 A4 排版，采用 React 原生渲染，未引入原版网关或全局脚本。

## 数据与口径

新增 GET /api/v1/bridges/{id}/monitoring-report?from=YYYY-MM-DD&to=YYYY-MM-DD。
先验证桥梁可访问范围，取得当前有效点位/设备/指标及阈值，再在 APP_DB 对有效通道一次 SQL 聚合。
统计范围为北京时间开始日00:00（含）至结束日次日00:00（不含），最多31个自然日。
使用 bm_monitor_sample 中非删除版本，全量 count/min/max/avg，不读取曲线接口的2000点截断结果。
同一通道元数据重复时去重；城市、点位、设备及 NULL 指标匹配保留。数据库故障返回错误，不生成空报告。
SQL 依赖 APP_DB 的普通 CTE、VALUES、IS NOT DISTINCT FROM；尚需实际排水库验证，不以 JDBC 驱动推断兼容。
来源元数据接口未修改，来源库既有扩展的 Vastbase 验证边界仍按 agent-vastbase-compatibility.md。

报告包括概况、指标统计、阈值核对、技术评价状态、质量检查、建议、附图及全部通道明细。
“有数据通道比例”不称在线率；样本按有效数加权统计均值。单位标注为字典参考单位。
当前阈值 boundaryConvention=UNSPECIFIED，且可能存在同级多区间，暂不自动判定一级/二级/三级超限。
保留原始阈值及问题说明；未接入定检基线/频率比/冲击比，结构评分明确为未评价，不套用万福固定分数。
无数据不输出“无报警”“结构安全”。编号每次生成唯一，生成时间与数据覆盖时间分开。
数据质量只检查空值、少量样本、缺阈值及来源阈值问题，不声称完成量纲或完整率检测。

## 打印与生命周期

预览为独立 React portal，使用转义文本输出。打印隐藏应用其余界面及预览工具条，A4纵版、重复表头、避免单行跨页。
浏览器“打印 / 导出 PDF”打开本机打印对话框，并非服务端 PDF 下载。
关闭/Escape 恢复页面；请求可取消，切换桥梁重新挂载组件避免旧桥结果展示。
首版不持久归档、不审批、不签章。后续补传/修订、元数据变化会影响重新生成结果；原文明确标注。
元数据与实测来自不同数据库，不宣称跨库事务快照；实测聚合自身为单语句快照。
