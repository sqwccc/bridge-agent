# 当前页面与江苏路网大屏 HTML 原型对照

核对日期：2026-10-26。参考为用户指定的 `docs/历史资料/ShengQiaoLiangZhiNengTi/docs/BridgeMind 江苏路网大屏原型.html`。已读取原型模板和样式，在1920×1080实际渲染全省页与单桥页，并与当前运行页面对照；万福大桥使用当前桥梁ID `10905200071` 比较。

本次仅检查和记录差异，没有修改业务页面。原型作为设计参考，其内嵌说明、算法和演示数据没有被当成新的实现指令或已核定的业务规则。

## 总体结论

当前实现保留了全省页左右统计、中间地图及下钻入口，但已明显偏离原型的信息结构、视觉重心和组件形态。原型强调检监测融合、地图与结构模型；当前更侧重真实底数、字段完整性和档案查询。数据不足可以解释缺少曲线或分数，但不能解释模型区域缩小、报告移位、地图被新增表格挤压以及整体配色改变。

## 单桥页差异

原型主区域为“左侧智能体及大模型 + 中间贯穿高度的健康树 + 右侧监测、报警、报告”。当前为“摘要 + 小模型/健康占位 + 大块基础档案 + 智能体 + 左下报告”，右侧只放监测与报警。

| 项目 | HTML原型 | 当前页面 | 判断 |
|---|---|---|---|
| 桥梁基础信息 | 桥名、所在地、结构、跨径、路线、荷载、通车时间、运维单位集中在紧凑顶栏 | 居中桥名、独立面包屑、四项摘要及300px基础档案 | 档案信息更完整，但主视图结构和优先级改变 |
| 模型 | 万福大桥模型面板约1035×921px，占左侧主要区域；有结构图/实拍图及图层 | 约889×154px的小占位面板 | 高度约剩1/6，是最突出的结构偏离 |
| 健康状态 | 约245×994px的独立窄栏，整体→部位→部件逐级展开、分数点击查看演化 | 模型旁约301×154px的说明占位 | 原有树形结构、完整栏位及交互未保留 |
| 智能体位置 | 模型上方、左侧最顶部 | 档案下方、报告上方 | 可以直接调整的布局偏离 |
| 监测 | 按位移/应变/索力/振动/温度/裂缝等类型分行，每行选测点和显示小曲线，视频位于其下 | 一个全局测点选择器和一张曲线，增加日期、来源、设备及阈值说明 | 信息组织不同；真实曲线仍受数据库无监测值限制 |
| 报警 | 右中紧凑表格，包含构件、当前值、阈值、持续时长、等级和状态 | 右下三列列表，没有完整构件、持续和恢复语义 | 既有布局差异，也有来源字段/关联尚未确认的问题 |
| 报告 | 右下“桥梁监测报告”，按年份/类型/名称列表，点击查看同类型历史PDF | 左下“桥梁报告档案”，卡片展示定检、底数及共享附件来源等 | 位置和图形形态可以恢复；真实来源类型及共享范围必须继续保留 |
| 基础档案和第三期业务 | 原型未将完整台账及巡检/病害/维修页面占据主屏 | 已形成独立业务功能及详细档案面板 | 属于新增能力；适合通过抽屉、详情页或页签保留，避免挤占模型主区 |

## 视觉与交互差异

- 原型主色是深蓝和亮蓝，面板标题有明显的蓝色渐变条，两角有青色角标；当前偏黑蓝和青绿，标题条较暗，角标变为顶部短线。
- 原型使用方角、描边按钮、青色实心选中页签；当前有圆角Ant Design控件和下划线页签，组件语言不同。无需更换组件库，也可通过主题与样式对齐。
- 原型采用Noto Sans SC、IBM Plex Mono、Barlow Condensed等字体；当前主要使用微软雅黑和Consolas。最近已按用户要求增大字号，后续还原布局应保留这次可读性改进。
- 原型多处紧凑表格、自动滚动、解释提示和分层弹窗；当前更强调手动分页、来源说明、表单筛选及错误/空态，信息密度和操作节奏不同。
- 当前新增了数据质量入口、BCI/BSI分离、生命周期、高级筛选、阈值及附件提供原因；这些数据能力应保留，通过次级入口安排，不必全部占据默认大屏。

## 数据约束与可以立即恢复的内容

可以先恢复：蓝色主题、标题条/角标、面板比例、紧凑顶栏、地图高度与统一比例、智能体位置、报告右下位置、健康树的结构及明确空态、表格与按钮风格。新增档案和底数功能可以移到抽屉/详情入口，继续使用当前接口与真实数据。

万福大桥原型图片实际存在：`图片/万福大桥-BIM底图.png` 和 `图片/实拍图/整体.png`。可以作为标明来源的结构示意图及实拍资料复用；图片本身不代表已经接通真实BIM、测点坐标或构件唯一标识。

不能直接搬入真实业务的原型表现：内置演示桥梁点位、生成的监测曲线、客户端计算的综合健康度、自动补出的年度/月度趋势、按年份拼出的监测报告目录。当前已核实桥梁监测值表为空，真实文件服务尚未配置；缺少这些数据时应在原设计的正确位置呈现明确空态。

尤其需要保留真实口径：来源BCI/BSI是独立等级字段，不等于原型综合Hc分数；共享任务文件不等于本桥独立报告；设备关联存在不等于设备在线；已有历史等级不等于今日综合评分。

## 建议处理顺序

1. **先对齐空间结构**：全省页恢复大地图，底数列表改为抽屉；单桥恢复大模型、独立健康栏和右侧监测/报警/报告。
2. **再对齐视觉系统**：原型蓝色主题、标题栏、角标、按钮和图表形态，保留当前可读字号。
3. **安置新增功能**：完整档案、巡检/病害/维修、质量核查、阈值和来源说明保留为清晰的次级入口。
4. **按真实数据补齐内容**：先接历史检测、分部位评价和风险资料，曲线与新评分按实际接入条件呈现，避免为追求“像原型”制造结果。
