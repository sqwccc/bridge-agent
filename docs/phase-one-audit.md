## 第一期规则与兼容

1. 列表、详情、大屏和告警使用同一桥梁公共 CTE。有效桥梁仍只排除删除及非江苏记录，移交、拆除不会自动从底数排除。
2. BCI/BSI 独立返回、命名、统计与筛选；1/2 为Ⅰ类合格/不合格，3～7 为Ⅱ～Ⅴ类 A～E。返回的是来源等级编码，不提供指数分值。
3. 空监测类型且存在有效设备时默认 2。有效设备要求最新未删除设备、最新有效桥梁监测点、同地市唯一桥梁归属。监测建设标识和来源原值仍保留。
4. 字段存在时为 PRESENT；字段为空且 sfyj=1、sfcc=1 或 cczt=1 时为 ALLOWED_EMPTY；生命周期都可识别且无豁免时为 MISSING；状态缺失或非法时为 UNDETERMINED。不把 cczt=2 自行加入豁免条件。
5. 保留 technicalGrade、monitoringType、technicalGrades 及原有 dashboard/options 数组结构。新增统一字典接口，前端名称取自后端响应或字典。
6. monitoringType 筛选按有效分类执行，missing 表示有效类型为空，0 仅表示来源 0，不再与 NULL 合并。新筛选语义见接口文档。
