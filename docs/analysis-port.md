# 万福大桥分析页移植

入口：万福大桥详情中的“数据分析”，地址 `/bridges/10905200071/analysis`。
只为万福大桥开放，页面沿用现有登录/预览门禁。其他桥的同类路径不会展示万福数据。

## 内容与运行方式

保留来源版本“桥梁智能体_平台接入版_v3.2”的 A1–A8 与 V1 九个模块，包括评分、阈值分级、相关性、异常识别、索力、温度效应、趋势、振动与规则集。
使用原包的 `seed-data.js`、`live-vib.js`，保留桥名、单位、采集日期以及原算法中的参数假定和缺数说明，不显示演示角标。
数据与所需脚本全部随前端发布，不依赖桌面路径、原网关、业务数据库或 Dify。监测数据日期为 2026-10-21 至 2026-10-22，振动窗口为 2026-10-29（北京时间）。

React 页面外壳中的 iframe 仅允许脚本执行，CSP 禁止 connect、嵌套 frame、对象和表单提交；不能访问父页面 DOM 或写入系统状态。外壳只接收当前 iframe 发出的就绪/失败消息，加载超时或资源失败可重新加载。
参数在模块内存中调整，刷新后复原。不创建报警、不覆盖档案评分、不修改养护记录。A1 的“应用”仅将比值和否决条件用于本页分析。

静态包位于 `frontend/public/wanfu-analysis-v3.2/`。`source-manifest.json` 保存原始文件 SHA-256；Git 属性防止原始文件换行转换，格式化工具跳过此目录。
内核、布局、图表、UI 和两个数据包按原字节保留。`algo.js` 的修改限于：

- “实时”显示改为采集快照，“应用到全桥”改为本页分析；保留原版假定参数说明。

仅保留分析所需模块，不载入原版应用、云数据库、平台连接、问答或上传启动逻辑。本次对齐原算法行为，不重新认定原规则和规范引用。

## 2026-11-02 加载优化

默认 A1 不再下载或解析 `live-vib.js`（1,793,773 字节）。静态启动脚本使用 defer，先解析页面；振动数据仅首次点击 V1 时加载，同页后续切换复用。V1 加载失败可局部重试，加载中切到其他模块不会被异步回调切回。快照采集时间从原文件 window 元数据提取，原数据文件及算法、绘图函数未改动。外壳提示改为“正在初始化图表”，超过 500 ms 才显示，快速打开时避免闪烁。

对同一本地静态模块地址执行 3 次独立浏览器上下文冷加载，禁用缓存，设置 80 ms 延迟、1 MiB/s 下载带宽，以 A1 参数控件可见为结束：优化前 3404 / 3362 / 3368 ms，优化后 1003 / 923 / 918 ms，平均约 3.38 s → 0.95 s（减少 72%）。首次资源解码体积 2,304,441 → 512,425 字节（减少 78%）。这不包括 React 外壳、认证或实际内网穿透链路延迟。

验证：九个模块默认文字与 SVG 序列化结果的 SHA-256 优化前后全部一致；7 项浏览器测试覆盖参数、重置、缩放、入口隔离、缺数、沙箱禁止业务请求、静态资源失败、V1 按需请求与重试及快速切换。前端构建通过，lint 无错误（原版脚本既有警告保留）。截图检查 A1 与 1366 px 页面正常。
